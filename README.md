# 问君能有几多愁

一个 p5.js 互动小品：粉色晕染底上一江春水，粉色水纹缓缓流动，
细小的“愁”字沿轨迹漂流。

> 问君能有几多愁，恰似一江春水向东流。—— 李煜《虞美人》

## 在线观看

<https://lijiaxuan020128-del.github.io/wen-jun-neng-you-ji-du-chou/>

## 交互

- **点击画面**：暂停 / 继续流动
- **按 S**：保存当前画面为 PNG

## 运行

- 在线版直接打开上面的链接即可。
- 本地运行：把 `index.html` + `sketch.js` 放在同一目录，用浏览器打开 `index.html`
  （或放入 p5.js Web Editor 运行）。

## 技术

- p5.js 1.11.3（CDN 加载）
- 静态页面，无构建步骤
